# 🚀 Despliegue en Vercel

Tu landing page está lista para desplegarse en Vercel. Sigue estos pasos:

## Paso 1: Conecta tu repositorio a Vercel

1. Ve a [vercel.com](https://vercel.com)
2. Haz login con tu cuenta de GitHub
3. Click en **"New Project"**
4. Busca y selecciona el repositorio `gotita-tech/experimento-02`
5. Vercel detectará automáticamente que es un proyecto Next.js

## Paso 2: Configuración (opcional)

Los valores por defecto funcionan, pero puedes personalizarlos:
- **Framework**: Next.js (automático)
- **Build Command**: `npm run build` (automático)
- **Output Directory**: `.next` (automático)

## Paso 3: Deploy

1. Click en **"Deploy"**
2. Espera a que termine (2-3 minutos)
3. ¡Tu sitio estará en vivo! 🎉

## URL de tu sitio

Después del deploy, Vercel te dará una URL tipo:
```
https://experimento-02.vercel.app
```

## Actualizaciones futuras

Cada vez que hagas push a la rama `main`, Vercel automáticamente:
- Detecta los cambios
- Reconstruye el proyecto
- Despliega la nueva versión
